## 引言

咖啡因（1,3,7-三甲基黄嘌呤，$\ce{C8H10N4O2}$）是全世界消费最广泛的精神活性物质。从清晨的第一杯咖啡到深夜的提神茶饮，全球约 **80%** 的人口每日摄入咖啡因。它天然存在于60多种植物的豆、叶和果实中，包括咖啡豆、茶叶、可乐果、可可豆、马黛茶和瓜拉纳浆果。

咖啡因的独特之处在于：它既是一种植物次生代谢产物，在生态学中作为天然杀虫剂发挥防御功能；又是一个在人体中作用于中枢神经系统腺苷受体的药理学探针。然而，在咖啡因被人类消费数千年之后，直至1819年才被分离纯化。它的分子身份明确之后，关于其药理作用、代谢差异和健康影响的科学认知才逐步建立。

本文从咖啡因的化学本质与发现史出发，系统阐述其药代动力学、受体机制，深入分析其对中枢神经系统、心血管系统和代谢系统的作用，并讨论耐受性、戒断、过量毒性以及个体差异的遗传基础。

## 第一章 化学本质与发现史

### 1.1 分子结构与命名

咖啡因的化学名为 1,3,7-三甲基黄嘌呤（1,3,7-trimethylxanthine），分子式 $\ce{C8H10N4O2}$，分子量 **194.19**。它属于**甲基黄嘌呤**（methylxanthine）类生物碱，核心结构为黄嘌呤（xanthine），在1、3、7位氮原子上各连接一个甲基。

咖啡因的分子结构与**腺苷**（adenosine）具有显著的结构相似性。腺苷是ATP和DNA的组成部分，在遗传学和代谢中具有多种关键功能。这种结构相似性是咖啡因药理作用的核心基础——它能够以竞争性拮抗的方式结合腺苷受体，从而阻断腺苷的生理效应。

### 1.2 发现简史

人类消费含咖啡因植物的历史可追溯至数千年前。咖啡的起源地是埃塞俄比亚，16世纪起多位欧洲植物学家对 *Coffea arabica* 进行了描述。

咖啡因的**纯化**发生在 **1819年**。德国化学家 **Friedrich Ferdinand Runge** 在诗人歌德的建议下，从咖啡豆中首次分离出纯的咖啡因。1823年，法国化学家 **Jean-Baptiste Dumas** 和 Pelletier 完成了咖啡因的首个元素分析。**1827年**，Runge 又在可可豆中发现了可可碱（theobromine），1838年 Mulder 在茶叶中发现了茶碱（theophylline）。这三种甲基黄嘌呤构成了天然精神活性生物碱的核心家族。

### 1.3 植物来源与含量

| 来源 | 咖啡因含量（约） |
|------|-----------------|
| 咖啡豆（阿拉比卡） | 0.8-1.4% |
| 咖啡豆（罗布斯塔） | 1.7-4.0% |
| 茶叶 | 2-5% |
| 可可豆 | 0.1-0.4% |
| 可乐果 | 1-3.5% |
| 瓜拉纳浆果 | 2-7% |

不同加工方式和冲泡方法会显著影响最终饮品中的咖啡因含量。一杯标准美式咖啡（240 mL）约含 **80-100 mg** 咖啡因，一杯浓缩咖啡（30 mL）约含 **60-80 mg**，一杯红茶（240 mL）约含 **40-60 mg**，一杯绿茶约含 **20-40 mg**，一罐可乐约含 **30-40 mg**。

## 第二章 药代动力学

### 2.1 吸收与分布

咖啡因口服后几乎完全被吸收，生物利用度接近 **100%**。空腹状态下，约 **45分钟** 内达到血浆峰浓度；进食后吸收可能略微延迟。咖啡因具有较高的脂溶性，能够穿透所有生物膜，包括血脑屏障和胎盘屏障。

分布容积约为 **0.6 L/kg**，与体内总水量相当。血浆蛋白结合率约为 **10-36%**，相对较低。

### 2.2 代谢：CYP1A2的核心角色

咖啡因的代谢主要在肝脏中进行，**95%以上** 由细胞色素P450酶系代谢。其中 **CYP1A2**（细胞色素P450 1A2）负责约 **80%** 的咖啡因代谢，是决定咖啡因清除速率的**核心酶**。

主要代谢途径包括：

1. **N-3-去甲基化**：生成**副黄嘌呤**（paraxanthine，1,7-二甲基黄嘌呤），约占 **80%**——这是咖啡因代谢的主要产物，也是其代谢活性的主要承担者
2. **N-1-去甲基化**：生成**茶碱**（theophylline，1,3-二甲基黄嘌呤），约占 **11%**
3. **N-7-去甲基化**：生成**可可碱**（theobromine，3,7-二甲基黄嘌呤），约占 **4%**

副黄嘌呤是咖啡因脂解作用的主要贡献者，具有增强脂肪分解和血浆游离脂肪酸水平的作用。茶碱在临床上用于治疗哮喘和COPD，具有支气管扩张作用。可可碱则是可可中的主要生物碱，具有温和的利尿和血管扩张作用。

### 2.3 半衰期与影响因素

咖啡因的消除半衰期在健康成人中约为 **3-7小时**，个体差异显著。影响半衰期的主要因素包括：

| 因素 | 对半衰期的影响 |
|------|---------------|
| 吸烟 | 缩短约 **50%**（CYP1A2诱导） |
| 口服避孕药 | 延长约 **50-100%**（CYP1A2抑制） |
| 妊娠（晚期） | 延长至 **9-11小时** |
| 肝病（肝硬化） | 显著延长 |
| 新生儿 | 极长（80-100小时） |
| 氟喹诺酮类抗生素 | 延长（CYP1A2抑制） |

新生儿因肝脏CYP1A2活性极低，咖啡因半衰期可达80-100小时。这也是为什么咖啡因（枸橼酸咖啡因）被用于治疗早产儿呼吸暂停——在这些婴儿体内，咖啡因的作用持续时间足够长，可维持有效的呼吸刺激。

## 第三章 受体机制：腺苷拮抗

### 3.1 腺苷受体的生理功能

腺苷是中枢神经系统中的一种**抑制性神经调质**。在神经元活动增加时，ATP被消耗，腺苷作为ATP的代谢产物在细胞外积累。腺苷作用于其受体，降低神经元的兴奋性，从而形成一个负反馈环路，调节睡眠-觉醒周期、觉醒水平、疼痛感知和脑血流。

腺苷受体有四种亚型：**A₁、A₂A、A₂B 和 A₃**，均为G蛋白偶联受体。其中 **A₁ 和 A₂A** 是咖啡因的主要作用靶点。

- **A₁ 受体**：广泛分布于大脑皮层、海马、小脑和脊髓，激活后抑制神经元放电
- **A₂A 受体**：高度富集于纹状体，激活后调节多巴胺能信号

### 3.2 咖啡因的拮抗机制

咖啡因是一种**竞争性拮抗剂**，以与腺苷相似的亲和力结合A₁和A₂A受体，但不激活它们。它通过占据受体位点来**阻断腺苷的抑制作用**。

这一机制在分子水平上表现为：当咖啡因占据A₁受体时，腺苷无法降低神经元的兴奋性，因此神经元活动相对增加。在A₂A受体水平上，咖啡因阻断腺苷对多巴胺能信号的抑制，间接增强多巴胺的作用。

### 3.3 腺苷受体拮抗的功能后果

| 腺苷的正常效应 | 咖啡因阻断后的效应 |
|--------------|-------------------|
| 促进睡眠 | 延迟入睡、减少总睡眠时间 |
| 降低觉醒水平 | 提高警觉性和注意力 |
| 血管扩张（脑） | 脑血管收缩（可能引起头痛缓解） |
| 抑制多巴胺信号 | 间接增强多巴胺效应 |
| 抗炎作用 | 可能减弱抗炎效应 |

咖啡因的"提神"作用并非直接刺激神经系统，而是通过**阻断"刹车"**——腺苷是人体内源的促睡眠物质，咖啡因阻断了它的作用，从而产生觉醒效应。

## 第四章 中枢神经系统效应

### 4.1 警觉性与认知功能

咖啡因对警觉性和认知功能的影响得到了大量研究的证实。低至 **75 mg** 的咖啡因即可提高警觉性和反应时间。在睡眠剥夺条件下，咖啡因能显著维持注意力、警觉性和执行功能。

一项系统综述指出，咖啡因对认知的影响主要体现在：

- **警觉性**：降低困倦感，提高持续注意力
- **反应时间**：缩短简单和选择反应时间
- **工作记忆**：部分研究显示轻度改善
- **情绪**：提高自我报告的能量感和幸福感

### 4.2 对睡眠的影响

咖啡因对睡眠的影响与剂量和服用时间密切相关。咖啡因的半衰期为3-7小时，因此在睡前6小时摄入咖啡因仍可能显著影响睡眠质量。

即使在睡前 **6小时** 摄入 **400 mg** 咖啡因，也会：
- 延长入睡潜伏期
- 减少总睡眠时间
- 降低睡眠效率
- 减少慢波睡眠和REM睡眠

### 4.3 与精神疾病的关系

咖啡因与精神疾病的关系复杂。在**精神分裂症**患者中，咖啡因摄入量通常较高，可能与自我用药（缓解药物副作用或疾病症状）有关。在**焦虑障碍**患者中，咖啡因可能加重焦虑症状，尤其是在高剂量下。

DSM-5将**咖啡因中毒**（caffeine intoxication）和**咖啡因戒断**（caffeine withdrawal）列为正式诊断，但**咖啡因使用障碍**（caffeine use disorder）被列为"需要进一步研究的状况"。

## 第五章 心血管与代谢效应

### 5.1 心血管系统

咖啡因对心血管系统的影响是双相的，且存在**耐受性**。

**急性效应**：
- 血管收缩（脑、皮肤、内脏）——这也是咖啡因用于缓解头痛的基础
- 心率增加（低剂量）或心率减慢（高剂量，通过迷走神经反射）
- 血压升高约 **5-10 mmHg**（收缩压和舒张压均升高）
- 血浆儿茶酚胺水平升高

**长期效应**：
- 血压升高效应在**耐受**后减弱
- 大规模流行病学研究显示，习惯性咖啡因摄入与**心血管疾病风险增加无关**
- 适量咖啡摄入（3-4杯/天）甚至与**心血管疾病风险降低**相关

### 5.2 代谢系统

咖啡因对代谢的影响是当前研究的热点。**副黄嘌呤**（咖啡因的主要代谢产物）是脂解作用的主要贡献者。

| 代谢效应 | 机制 |
|---------|------|
| **脂解增强** | 副黄嘌呤抑制磷酸二酯酶，增加cAMP，激活脂肪酶 |
| **基础代谢率升高** | 增加能量消耗约 **3-11%** |
| **脂肪酸氧化增强** | 运动时增加脂肪利用，节约糖原 |
| **胰岛素敏感性** | 短期可能降低，长期影响不确定 |

值得注意的是，咖啡因对代谢的影响在**运动**时更为显著。运动前摄入咖啡因可提高脂肪氧化率，延缓糖原耗竭，从而改善耐力表现。

### 5.3 咖啡因与疼痛

咖啡因具有**辅助镇痛**作用。它通过以下机制增强镇痛效果：

- 阻断腺苷的痛觉促进作用
- 收缩脑血管（缓解血管性头痛）
- 增强其他镇痛药的效力

这解释了为什么许多复方镇痛药（如对乙酰氨基酚+咖啡因、阿司匹林+咖啡因）中会加入咖啡因。

## 第六章 耐受性、戒断与过量

### 6.1 耐受性

长期摄入咖啡因会产生**耐受**，表现为：

- 对咖啡因的警觉性增强效应减弱
- 对咖啡因的血压升高效应减弱
- 需要更高剂量才能达到相同的效果

耐受的机制主要是**腺苷受体上调**——长期阻断腺苷受体后，机体代偿性地增加受体数量。这也解释了戒断症状的产生。

### 6.2 戒断综合征

DSM-5将咖啡因戒断列为正式诊断。戒断症状通常在**突然停止咖啡因摄入后12-24小时**出现，**20-48小时**达到高峰，持续**2-9天**。

| 戒断症状 | 发生率 |
|---------|--------|
| 头痛 | 最常见，约 50% |
| 疲劳/嗜睡 | 常见 |
| 注意力不集中 | 常见 |
| 情绪低落/易怒 | 常见 |
| 流感样症状 | 较少见 |

戒断症状的机制与**腺苷受体上调**密切相关。当咖啡因突然撤除时，上调的腺苷受体暴露于正常的腺苷水平，产生过强的抑制效应——这就是头痛、疲劳和嗜睡的原因。

### 6.3 过量与中毒

咖啡因的**致死剂量**估计为 **10-14 g**（约相当于100杯咖啡），但个体差异极大。**咖啡因中毒**（caffeinism）的临床表现包括：

- 失眠、烦躁、紧张
- 面部潮红、多尿
- 胃肠道不适
- 肌肉抽搐
- 心动过速、心律失常
- 严重时出现癫痫发作和昏迷

**能量饮料**是咖啡因过量中毒的主要来源。能量饮料中的咖啡因浓度可高达 **80-500 mg/罐**，且常与糖、牛磺酸、瓜拉纳提取物等成分共同摄入，可能产生协同效应。

## 第七章 遗传与个体差异

### 7.1 CYP1A2 基因多态性

CYP1A2基因的 **-163C>A** 多态性（rs762551）是决定咖啡因代谢速率的主要遗传变异。

| 基因型 | 代谢速率 | 咖啡因半衰期 |
|--------|---------|-------------|
| **AA 纯合子** | 快速代谢 | 约 2-3小时 |
| **AC 杂合子** | 中等代谢 | 约 3-5小时 |
| **CC 纯合子** | 慢速代谢 | 约 5-7小时 |

约 **50%** 的人群携带AA基因型（快速代谢者），约 **40%** 携带AC型，约 **10%** 携带CC型（慢速代谢者）。

### 7.2 腺苷受体基因多态性

**ADORA2A** 基因的 **1976T>C** 多态性（rs5751876）与咖啡因的焦虑效应相关。携带 **C等位基因** 的个体在摄入咖啡因后更容易出现焦虑和失眠症状。

这一发现解释了为什么有些人在饮用咖啡后感到焦虑和不安，而另一些人则毫无影响。

### 7.3 咖啡因与心血管风险的个体化

CYP1A2基因型与咖啡因对心血管风险的影响存在交互作用：

- **慢速代谢者（CC型）**：每日摄入 **2-3杯** 咖啡时，心肌梗死风险增加约 **36%**，且高血压风险增加
- **快速代谢者（AA型）**：咖啡摄入与心肌梗死风险**无关**，甚至可能降低风险

这提示咖啡因的心血管效应**不能一概而论**，需要考虑个体的遗传背景。

## 第八章 咖啡因与健康：综合证据

### 8.1 全因死亡率

多项大规模队列研究的荟萃分析显示，适量咖啡消费（**3-4杯/天**）与**全因死亡率降低**相关。这一关联在多项研究中表现出**U型曲线**：不喝咖啡和大量喝咖啡的人死亡率较高，而适量饮用者死亡率最低。

### 8.2 2型糖尿病

咖啡消费与**2型糖尿病风险降低**相关。每增加一杯咖啡/天，2型糖尿病风险降低约 **7-8%**。这一保护效应在**无咖啡因咖啡**中也存在，提示不仅仅是咖啡因的作用——其他成分（如绿原酸、镁）也可能参与。

### 8.3 帕金森病与神经退行性疾病

咖啡因摄入与**帕金森病风险降低**之间存在较强的关联。在男性中尤为显著，每日摄入咖啡因可降低帕金森病风险约 **25-30%**。

咖啡因的腺苷A₂A拮抗作用可能是其神经保护效应的机制——A₂A拮抗剂已被开发为帕金森病的潜在治疗药物。

### 8.4 肝脏保护

咖啡消费与**肝纤维化和肝细胞癌风险降低**相关。在慢性肝病患者中，咖啡摄入与肝纤维化进展减慢和肝癌风险降低相关。

## 总结

咖啡因的百年科学史折射出现代药理学的核心命题：**同一分子，在不同的剂量、不同的个体、不同的暴露时长下，可以产生截然不同的效应。**

| 维度 | 核心结论 |
|------|---------|
| **化学本质** | 1,3,7-三甲基黄嘌呤，$\ce{C8H10N4O2}$，甲基黄嘌呤类生物碱 |
| **核心机制** | 竞争性拮抗A₁和A₂A腺苷受体 |
| **主要代谢酶** | CYP1A2（约80%） |
| **半衰期** | 3-7小时，受吸烟、口服避孕药、妊娠、肝病影响 |
| **中枢效应** | 提高警觉性、延迟睡眠、增强多巴胺信号 |
| **心血管效应** | 急性升压，耐受后减弱，适量与风险降低相关 |
| **耐受与戒断** | 腺苷受体上调是核心机制 |
| **遗传差异** | CYP1A2 -163C>A 决定代谢速率，ADORA2A 决定焦虑易感性 |
| **健康效应** | 适量摄入与全因死亡率降低、2型糖尿病风险降低、帕金森病风险降低相关 |

从埃塞俄比亚山地的咖啡树到全球80%人口每日摄入的精神活性物质，咖啡因的旅程是一部跨越大洲、贯穿数千年的科学史。
