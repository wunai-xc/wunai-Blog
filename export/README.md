# 导出说明：博客视觉迭代

`visual-refresh.patch` 是此前暖色改版的**历史基线补丁**，不是当前工作区的完整补丁；请勿在现有工作区再次应用。

## 这次迭代

- 暖纸 / 暖黑主题与赭石主色保持不变。
- 卡片、面板、按钮、标签、缩略图恢复直角，首页分页点改为方形。
- 首页增加低对比度的纯 CSS 几何网格、水平分隔线和栏目标题细线。
- 卡片 hover 用左侧 2px 强调线、边框变色与短距离轴向位移；移除文章 3D 倾斜、合集指针跟随光斑与按钮液态滤镜。
- 入场从弹跳阶梯改为单程淡入 / 平移；长文不再纵向缩放；图标不再持续旋转或弹跳。
- 保留键盘焦点轮廓、系统 reduced-motion 和站内关闭动画设置。

实际修改以工作区文件为准。请在 `my-app` 下运行 `npm run lint`、`npm run build`，并手动检查中英双语首页、文章列表、合集、文章详情与页脚，在桌面 / 手机宽度下切换亮暗主题、Tab 键导航、减少动画以及打印预览。
